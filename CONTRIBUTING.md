# Contributing

This repository is a personal open hardware portfolio and reference design. Small issues, review notes, and documentation fixes are welcome.

## Useful Contributions

Helpful contributions include documentation corrections for RTL, synthesis, or backend notes; small testbench or script cleanup suggestions; clear bug reports with the file path, module name, expected behavior, and observed behavior; and storage-safety improvements that keep generated artifacts out of future commits.

## Please Avoid

Please avoid uploading EDA databases, waveform dumps, model checkpoints, or other large generated files. Do not replace source files with tool-specific outputs or submit broad rewrites without a clear review reason.

## Reporting an Issue

When reporting an issue, include the affected file or module, the tool or simulator if relevant, concise steps to reproduce, and the expected and observed behavior.

This project currently keeps all rights reserved. Please ask before reusing source code outside review or educational discussion.
