# Contributing

This repository is a personal open hardware portfolio and reference design. Small issues, review notes, and documentation fixes are welcome.

## Good contributions

- Documentation corrections for RTL, synthesis, or backend notes.
- - Small testbench or script cleanup suggestions.
  - - Clear bug reports with file path, module name, expected behavior, and observed behavior.
    - - Storage-safety improvements that keep generated artifacts out of future commits.
     
      - ## Please avoid
     
      - - Uploading EDA databases, waveform dumps, model checkpoints, or other large generated files.
        - - Replacing source files with tool-specific outputs.
          - - Submitting broad rewrites without a clear review reason.
           
            - ## Reporting an issue
           
            - Please include:
           
            - - affected file or module;
              - - tool or simulator used, if relevant;
                - - concise steps to reproduce;
                  - - expected and observed behavior.
                   
                    - This project currently keeps all rights reserved. Please ask before reusing source code outside review or educational discussion.
